## 🎯 Pro Tips

1. **Bookmark** [NAVIGATION_QUICK_REF.md](./NAVIGATION_QUICK_REF.md) for quick lookups while coding
2. **Reference** all route constants from `ROUTES` - never use hardcoded strings
3. **Use** appropriate methods: `push()` for depth, `replace()` for transitions, `reset()` for flows
4. **Check** examples in existing screens before implementing new patterns
5. **Look up** route paths in the ROUTES constant using IDE autocomplete
